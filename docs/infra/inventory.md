## Обновление браузерного плана

При подготовке каждого PR миграции обновляй строку соответствующего этапа в docs/infra/acceptance-report.md в том же PR. Укажи достигнутый результат, основание (номер PR или краткое описание проверки) и оставшееся условие приёмки. Для организационного PR достаточно записать его результат в описании PR. Для изменений в приватном продукте после PR синхронизируй в этом репозитории только разрешённое резюме. Сохраняй три колонки таблицы и по одной строке на этап.

Приватная страница OpenAI Sites читает таблицу из main и журнал PR из публичного GitHub при открытии, возврате на вкладку и раз в минуту на активной вкладке. Перед завершением работы проверь, что PR появился в журнале, а после merge — что обновился этап. Если GitHub недоступен, страница показывает предупреждение и позволяет открыть оригинал.
