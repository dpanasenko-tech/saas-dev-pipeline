# Целевая архитектура и выбор сети

MacBook → приватный SSH → Beelink → GitHub (код и синтетические фикстуры). GitHub Actions → одноразовый runner → registry (образы с SHA и digest). Отдельные deploy-процессы читают registry по digest. FirstVDS обслуживает HTTPS напрямую, российское объектное хранилище принимает зашифрованные копии. Агент, runner и серверы приложения имеют различные учётные записи.

Первый пилот — Tailscale только между MacBook и Beelink. MFA и grant с Mac на TCP/22 Beelink, обычный OpenSSH, без exit node и объявления подсетей. Измерить RTT, direct/relay, восстановление после смены IP, перезапуска и переключения Amnezia. Сверить DNS, IPv4/IPv6 и default route до/после, в том числе из внешней сети. Публичные SaaS и БД не включать в tailnet.

Резерв — исходящий WireGuard с выделенным административным peer либо ограниченный reverse SSH до loopback Timeweb и ProxyJump. Отдельные ключи и права forwarding только для нужного порта, keepalive и systemd restart. Перед изменениями экспортировать конфигурацию Amnezia в защищённое хранилище, проверить восстановление. Согласовать эксплуатацию одного варианта по доступности, маршрутам, тарифу и сложности восстановления.

На Beelink один writer на worktree; раздельные temp, БД и порты. Сверить версии инструментов и поддержку фонового запуска. Хранить уникальные локальные изменения, dev-БД и recovery keys в зашифрованных копиях. На FirstVDS — два Compose project, независимые тома, пользователи ОС/БД, deploy credentials, сети и расписания. Только фронтовые сервисы входят в сеть ingress. Определить hard memory limits staging и приоритет prod после замеров. Общими точками отказа остаются ядро, диск, питание и proxy.
